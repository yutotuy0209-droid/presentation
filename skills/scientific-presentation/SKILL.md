# Scientific Presentation Skill

## Use when

Create or revise a technical, engineering, scientific, or research presentation.

## Goal

Make the evidence, method, and interpretation understandable with the fewest necessary slides.

## Rules

1. Give each slide one main claim or question.
2. Prefer figures, measured values, diagrams, and tables over explanatory paragraphs.
3. Always keep units, experimental conditions, axes, legends, and comparison baselines visible when they matter.
4. Separate measured facts from interpretation.
5. Do not repeat background once the audience has enough context.
6. Use the order Background → Problem → Method → Result → Discussion → Next step as a default, not a rigid template.
7. For progress meetings, emphasize what changed since the previous report.
8. If a figure cannot be read at presentation size, simplify it instead of shrinking it.
9. Preserve editable text/shapes when practical; rasterize only when fidelity is more important than editability.
10. Verify the final deck visually after generation.

## Output preference

- 16:9 by default
- concise titles that state the slide's point
- diagrams before long prose
- consistent margins and typography
- speaker notes only when they add information that should not appear on the slide
