# スライド最低品質基準（完成条件）

スライドの最低品質は加点要素ではない。AIが文章や図を生成した時点では完成扱いにせず、**内容検査 → 機械検査 → 実レンダリング → 画像レビュー → 修正**を必須とする。元の指摘事項の全文は [PROFESSIONAL_SLIDE_PROMPT.md](PROFESSIONAL_SLIDE_PROMPT.md) を参照。

## 必須検収チェック（ユーザー画像の13項目に対応）

| ID | 最低限守ること | 機械検査 | 最終判定 |
|---|---|---|---|
| Q01 | 1枚につき主要な主張は1つ。方針・手順・対象・日程を無理に混載しない | 情報密度の警告のみ | 人が論理を確認 |
| Q02 | 判断を要求するなら具体的な選択肢、推奨案、判断根拠を記載 | 見出し・選択肢の簡易検出 | 人が妥当性確認 |
| Q03 | 伴走者・価値最大化など内容のない定型句を避ける | 既知の語句に警告 | 人が全文章を確認 |
| Q04 | 別途相談・個別状況による等の丸投げを残さない | 典型句はエラー | 人が担当・条件・次行動を確認 |
| Q05 | 意味のない強調カギカッコを使わない | 自動判別困難 | 人が表記を確認 |
| Q06 | 列ごとに共通ラベルを重複させない | 典型ラベルに警告 | 人が表構造を確認 |
| Q07 | 見出しの繰り返し説明を付けない | 自動判別困難 | 人が文章を確認 |
| Q08 | 語途中・助詞直後で不自然に改行しない | 手動改行の一部に警告 | レンダリング画像で確認 |
| Q09 | 長文免責・注釈を読めない形で脚注に押し込まない | 長いfooterはエラー | 出典・必要な注記は読みやすさを確保 |
| Q10 | 無意味な縦線、ゼロ埋め番号、区切り線を足さない | 縦線エラー・番号警告 | 人が視覚検査 |
| Q11 | 横並びの枠の高さと端を揃える | 明示heightの相違に警告 | レンダリング画像で検証 |
| Q12 | 色分け・グレー背景には意味を持たせる | 自動判別困難 | 人が役割・比較意図を確認 |
| Q13 | 異なるブロック間の論理的対応を視覚的に示す | 自動判別困難 | 人が関係性を確認 |

## 完成の定義

- **機械検査**：`src/design_lint.py` および既存の構造検査でエラーがゼロである。warningは見落とさず解消するか、根拠を残して例外処理する。
- **内容検査**：1スライド1メッセージ、主張と根拠の対応、判断資料の比較軸と推奨案を確認する。数値や出典を創作しない。
- **画像検査**：出力形式の全ページを最終サイズでレンダリングし、はみ出し、余白、左右の高さ、改行、文字サイズ、注釈の可読性を確認する。生成コード上の座標だけで合格させない。
- **反復**：1つでも未達ならスライドの構成・情報量・配置を修正して再レンダリングする。「生成完了」は「検収完了」ではない。
- **証跡**：検査レポート、最終レンダリング画像、未解決事項を保存する。画像検査を実施していない場合は「未検収」と明示する。

## 注意すべき例外

科学・研究資料の不確実性の記述は「逃げ表現」ではない。条件、測定誤差、仮説の限界、根拠の強さを正確に記載すること。必要な法的注記やデータ出典も削除せず、読みやすい配置へ変更する。比較のために色や番号へ意味が付与されている場合は形式的に禁止しない。

## 実行

```bash
python src/design_lint.py examples/grid_deck_glanceable.json
python tests/test_design_lint.py
npm run build:grid
```

`build:grid` の `--strict` で機械検査エラーはブロックする。ただし自動Lintは意味・実レンダリングの検収を代替しない。
