# Presentation Structure Skill

## Use when

Choosing the overall flow of a presentation before rendering slides.

## Default patterns

### Scientific
Background → Problem → Method → Result → Discussion → Next step

### Research progress
Objective → Change since last report → Work performed → Result → Issue → Next action

### Comparison
Question → Criteria → Option A/B → Evidence → Difference → Decision context

### Story-driven
Context → Question/tension → Approach → Evidence → Meaning → Takeaway

## Selection rule

Choose the structure from the audience's information need. Do not force 起承転結 or any other narrative form when a direct technical structure is clearer.

## Slide-level rule

Every slide should be explainable as:

> Because the audience needs to know **X**, this slide shows **Y**, which supports **Z**.

If that sentence cannot be completed clearly, split, merge, or remove the slide.
